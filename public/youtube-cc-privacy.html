이 앱은 무엇인가요

youtube-cc 는 유튜브 채널 '누도움' 운영자가 자기 채널에 영상을 올리고, 올린 영상의 상태를 확인하려고 만든 개인용 도구입니다. 운영자의 컴퓨터에서만 실행되며, 다른 사람에게 제공하는 서비스가 아닙니다.

어떤 Google 권한을 쓰나요

  • youtube.upload — 운영자가 만든 영상을 운영자 채널에 올리고, 썸네일과 공개 예약 시각을 정합니다.
  • youtube.readonly — 운영자 채널의 이름과, 올린 영상의 목록 · 길이 · 공개 상태 · 공개 시각을 읽습니다.
  • youtube.force-ssl — 운영자가 올린 영상의 제목 · 설명을 고치고, 그 영상에 운영자 이름으로 댓글을 답니다.

무엇을 모으고 어디에 두나요

  • 운영자 본인 계정 하나만 씁니다. 다른 사람의 개인정보는 모으지 않습니다.
  • Google 이 준 허락 정보(토큰)는 운영자 컴퓨터의 비공개 파일에만 저장합니다. Google API 말고는 어디로도 보내지 않습니다.
  • 유튜브에서 읽은 정보는 운영자 채널을 운영하는 데만 쓰고, 팔거나 다른 사람과 나누지 않습니다.
  • 광고를 넣거나 사용자를 추적하지 않습니다.

youtube-cc 가 Google API 에서 받은 정보를 쓰는 방식은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

YouTube API 서비스

이 앱은 YouTube API 서비스를 사용합니다. 그래서 YouTube 서비스 약관과 Google 개인정보처리방침이 함께 적용됩니다.

허락을 거두려면

Google 계정의 타사 앱 및 서비스 화면에서 youtube-cc 의 허락을 언제든 거둘 수 있습니다. 거두면 이 앱은 더 이상 채널에 접근하지 못합니다.

Summary in English

youtube-cc is a personal tool used only by the operator of the YouTube channel “누도움” (@someonewillneedit) to upload videos to that channel and to read the status of its own videos. It uses the YouTube API Services with the operator's own Google account only and does not collect data about anyone else. OAuth tokens are stored only in a private file on the operator's computer and are sent nowhere except Google APIs. YouTube data is used only to run that channel and is never sold or shared. The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
